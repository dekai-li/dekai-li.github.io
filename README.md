# Dekai Li Academic Homepage — V1.2

Clean, static academic homepage for GitHub Pages.

## Structure

- `index.html` — homepage
- `styles.css` — all site and CV styles
- `script.js` — mobile navigation + footer year
- `cv.html` — English CV
- `cv_zh.html` — Chinese CV
- `favicon.svg` — browser tab icon
- `robots.txt` / `sitemap.xml` — basic search-engine metadata
- `assets/profile.png` — portrait

## Deploy

Upload these files to the root of the `dekai-li.github.io` repository and commit to `main`.
GitHub Pages should be configured to deploy from `main` / `(root)`.
